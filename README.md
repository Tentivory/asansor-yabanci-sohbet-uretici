# ASANSÖR YABANCI SOHBET ÜRETİCİ

## Bu Nedir? (Ciddi Anlatım)

İnsanlığın en büyük problemlerinden biri: Asansörde yabancı biriyle ne konuşulacağı. Sessizlik, utangaçlık, varoluşsal kriz...

Bu proje, bu sorunu **bilimsel** ve **absürt** bir şekilde çözer. Kodumuz, rastgele, anlamsız ve eğlenceli sohbetler üretir. Gerçekten çalışır. Deneyin, utanmayın.

## Nasıl Kullanılır?

```bash
python sohbet_uretici.py
```

Bir sohbet çıkar. Asansöre binin, yabancıyla konuşun. Sonuçlar garanti değil, ama eğlenceli.

## Özellikler

- %100 Türkçe saçmalık
- Sonsuz (neredeyse) sohbet kombinasyonu
- Asansör müziğiyle uyumlu
- Sıkışma riski yüksek (sorumluluk reddi)
